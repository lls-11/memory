# 第一部分 · DBT 用于危机干预

## 1. 生物社会理论（Biosocial Theory）

Linehan 对情绪失调的解释：**不是「人有问题」，而是「一种生物学倾向」与「一种环境反应」
在时间里反复相乘**。

### 1.1 两个因素

**① 生物学上的情绪脆弱性**，三个可观察成分：

| 成分 | 表现 | 危机现场看到的样子 |
|---|---|---|
| 高敏感性（低阈值） | 别人不会有反应的刺激就触发情绪 | 一句中性的澄清问句被体验为质问 |
| 高反应性（强幅度） | 一旦启动就非常强烈 | 从平静到崩溃只用几秒 |
| 回落缓慢 | 回到基线需要很久 | 会谈结束一小时后仍在高唤起 |

第三条最容易被忽略，却决定了危机干预的节奏：**上一次情绪还没落地，下一波就叠上来了**，
于是当事人长期生活在基线之上——这就是「慢性高唤起」的来源。

**② 无效化环境（invalidating environment）**，三种典型反应：

- **否定私人体验**：「这没什么好难过的」「你就是想太多」「你不是真的想死」
- **对情绪表达间歇性强化**：平时的求助被忽略，**升级到极端时才被认真对待**——
  于是极端表达被强化成了有效的沟通方式
- **过度简化问题解决的难度**：「想开点就好了」——暗示做不到是因为不够努力，
  当事人因此习得**自我否定**：连自己的情绪都不信任

### 1.2 关键在「交互」（transactional），不在归因

不是「父母造成的」也不是「基因造成的」。是一个双向升级的螺旋：
脆弱的孩子 → 难以被读懂的强烈反应 → 照料者疲惫、否定或时灵时不灵地回应 →
孩子更不信任自己的体验、表达更极端 → 环境更无效……

> **这一条是临床立场，不只是理论**：它让你在危机中既**不指责当事人**（这是习得的，
> 且有生物学基础），也**不指责家属**（他们在应对一个难以应对的处境）。
> 在家属在场的危机会谈里，这句话本身就是最有效的降温工具之一。

### 1.3 对危机干预的直接推论

| 理论要点 | 危机现场的操作含义 |
|---|---|
| 高唤起下认知窄化 | 此时当事人**做不了**方案比较、看不见未来、想不起拒绝自杀的理由。先降唤起，再谈解决 |
| 任何「被感知为否定」都会推高唤起 | 说理、保证、纠正事实、过早给建议，都可能被体验为否定 |
| 回落缓慢 | 别用「他刚才不是好了吗」判断安全；降温需要的时间比你以为的长 |
| 间歇强化史 | **不要只在极端行为出现时才给予关注**，否则你正在训练升级（见 §4.4 偶联管理） |
| 自我否定 | 当事人会说「我这样不应该」——**验证情绪本身**，往往比讨论事件更快生效 |
| 情绪是「真的很难忍」 | 「忍一忍」不是干预。要给具体的、生理层面的降唤起技能（TIP，见 §3.2） |

## 2. 辩证思维（Dialectics）

### 2.1 核心命题

1. **对立的双方可以同时为真**（both/and 取代 either/or）
2. 真相在**综合（synthesis）**里，而综合不是折中——折中是各让一半，
   综合是找到一个把双方的有效性都容纳进去的更大框架
3. 现实在**持续变化**中，所以任何「结论」都是暂时的

DBT 的母辩证：**「你此刻是尽了全力的」 与 「你需要做得更多、更努力、更有效」
——两句都是真的。**

### 2.2 危机中最常见的几组张力

| 一极 | 另一极 | 综合的方向 |
|---|---|---|
| 接纳当下的痛苦 | 推动行为改变 | 「这痛苦是真实且合理的；**同时**我们此刻要一起找一个能撑过今晚的办法」 |
| 尊重自主 | 保护生命 | 在**可协商的范围内**最大化其选择权（去哪家医院、谁陪同、先联系谁） |
| 共情自杀带来的解脱感 | 不强化自杀作为解决方案 | **验证情绪，不验证方案**（见 §3.3） |
| 「危机是真的」 | 「危机会过去」 | 不否认此刻的绝望，同时把时间维度引入（「情绪不会永远停在峰值」） |
| 当事人是受害者 | 当事人需为行为负责 | 两者不冲突：遭遇不公 **且** 解决方式仍然要由自己承担后果 |

### 2.3 辩证策略（可在会谈中直接用）

- **寻找有效性内核（kernel of truth）**：对方最不可理喻的那句话里，哪一部分是对的？先说那部分。
- **魔鬼代言人（devil's advocate）**：对方说「我想活下去」时，你反过来质疑
  （「可是活着这么疼，为什么要留下来？」）——让对方为「活下去」辩护。**这是承诺策略的主力**，
  但必须在联盟稳固时使用，且不用于唤起极高或当事人正在解离时。
- **隐喻**：绕开正面对抗。「现在像在一间着火的屋子里，我们先出门，不在里面讨论房子该怎么装修。」
- **从悖论进入**：「我完全接受你现在的样子，同时我不会帮你保持现在的样子。」
- **允许自然变化**：不把「情绪反复」当治疗失败。
- **扬弃极端立场**：注意自己有没有掉进「要么住院要么什么都不做」。

### 2.4 一元化（non-dialectical）陷阱自查

| 掉进哪一极 | 现场表现 | 后果 |
|---|---|---|
| 只有接纳 | 全程共情，不提任何行动 | 会谈结束时当事人仍然没有今晚的办法 |
| 只有改变 | 直接列清单、布置作业 | 被体验为「你也觉得我不该这样」→ 关闭 |
| 只有控制 | 一有意念就报警/送急诊 | 破坏联盟、惩罚了坦诚、下次不再说实话 |
| 只有自主 | 「这是你的选择」 | 在急性危险面前是失职 |

## 3. 接纳与改变策略

DBT 把技术分成两组，危机干预的技艺就在于**两组之间的配比与顺序**。

```
   唤起水平
    高 │████████  只能用接纳侧（验证、降唤起、陪伴）
       │
   可工作区间 ├──────  接纳为主 + 小剂量改变（一个具体的下一步）
       │
    低 │░░░░  可以做链分析、方案解决、技能训练、承诺工作
       └──────────────────────────────────► 时间
```

**原则：唤起水平决定你能用什么。** 在峰值上做方案解决，等于什么都没做还消耗了联盟。

### 3.1 接纳侧：验证（Validation）的六个层次

| 层次 | 做什么 | 例句 |
|---|---|---|
| **V1** | 清醒地在场、专注地听和观察 | （不打断、不多任务、用简短回应表明在听） |
| **V2** | 准确复述对方说的内容 | 「所以是她说完那句话之后，你才开始想这些的。」 |
| **V3** | 说出对方没说出口的 | 「听起来除了愤怒，还有一点……被丢下了？」（说错了就让对方纠正，这本身也有效） |
| **V4** | 依据**既往经历/生物学**来理解 | 「以每次你一表达就被打回去的经历看，你现在不敢开口是说得通的。」 |
| **V5** | 指出在**当下情境**中这反应是**正常合理**的 | 「刚刚被这样对待，任何人都会气。」——**危机中最有力的一层** |
| **V6** | 彻底真诚：以平等的人对待，而非「病人」 | 不用治疗腔，该笑就笑，必要时承认自己的局限和感受 |

**V5 与 V4 的区别很重要**：V4 是「以你的历史来看可以理解」（暗含「虽然不合常理」），
V5 是「这就是正常的」。**能给 V5 就不要停在 V4。**

**假验证（V0，要避免）**：
「我理解你的感受」（空洞）、「会好起来的」（过早保证）、「你很勇敢」（贴标签）、
「至少你还有……」（比较式安慰）、立刻转向解决方案（隐含「你的情绪不值得停留」）。

### 3.2 改变侧

| 策略 | 内容 | 危机中的用法 |
|---|---|---|
| **行为链分析** | 易感因素 → 诱发事件 → 想法/情绪/行动的链条 → 行为 → 短期后果 → 长期后果 | 危机**当次**只做粗链（找诱发点和一个可插入的环节），精细链分析放到危机后 |
| **方案解决** | 生成 → 评估 → 选择 → 排障（troubleshoot） | 一次只落实**一个**、今晚就能做的、不依赖他人配合的动作 |
| **偶联管理** | 不强化功能不良行为，强化有效行为 | 见 §4.4 |
| **认知调整** | 处理绝对化信念（「永远」「没人」） | 高唤起时无效，不要在峰值上辩论事实 |
| **暴露** | 对情绪本身的暴露（不回避、不阻断） | 「我们一起待在这个感觉里 90 秒，看它会不会变」 |
| **技能训练** | 见下 | 危机中的首选是**痛苦承受**技能 |

**危机中最常用的技能（按优先级）**：

- **TIP**（生理层面直接降唤起，最快）：
  **T**emperature 冷水扑面/握冰（激活潜水反射，心率下降）；
  **I**ntense exercise 短时剧烈运动；
  **P**aced breathing 呼气长于吸气；
  **P**aired muscle relaxation 紧张—放松配对呼吸。
  *（冷水法对心脏病、进食障碍导致的心动过缓、服用 β 受体阻滞剂者有风险，需先筛查。）*
- **STOP**：停 → 退一步 → 观察 → 觉察地行动（用于冲动出现的那几秒）
- **优缺分析（pros & cons）**：对「实施自伤/自杀行为」与「忍受这一波」各列短期/长期利弊——
  **提前在非危机时做好并随身携带**，危机中现做效果有限
- **自我安抚（五感）/ ACCEPTS 转移注意 / IMPROVE**
- **彻底接纳（radical acceptance）**：针对无法改变的丧失（注意：接纳 ≠ 认可）

### 3.3 配比原则（实操）

1. **先接纳后改变**：每一次改变推动，前后各包一层验证（「验证三明治」）。
2. **改变被拒绝 = 剂量过大**：对方一沉默/一对抗，立刻退回接纳侧，而不是加压。
3. **一次一个改变**：危机会谈里给两个以上任务，等于给零个。
4. **绝对不可验证的内容**：**不验证「自杀是有效的解决办法」这一结论**。
   正确形式是：「这么疼的时候想让它彻底停下来，我完全能理解 **（验证情绪与动机）**；
   同时我不会同意死亡是这里唯一的出口 **（不验证方案）**。」
5. **「你已尽力」和「还不够」要一起给**，只给前者是放弃，只给后者是指责。

## 4. 目标行为的优先排序（Target Hierarchy）

### 4.1 第一阶段的四级顺序

```
① 生命威胁行为          ← 只要本周发生过/正在发生，一律排第一
② 治疗干扰行为          ← 缺席、迟到、不填日记卡、不合作、治疗师这边的干扰行为
③ 严重影响生活质量的行为  ← 物质滥用、进食障碍、无家可归、法律问题、重性共病
④ 技能获得与泛化        ← 前三项不占用会谈时，把时间给技能
```

**这个顺序是刚性的**：不是「先谈重要的」，而是**只要上一级出现，就从上一级开始**。
但「从上一级开始」不等于「整场会谈只谈它」——处理完就往下走。

### 4.2 第一级内部还要再排

| 次序 | 行为 | 说明 |
|---|---|---|
| 1 | **急性自杀危机行为** | 正在进行/刚发生的自杀尝试、准备行为 |
| 2 | **非自杀性自伤（NSSI）** | 无论意图如何，一律作为一级目标 |
| 3 | **自杀相关的期待与沟通** | 「我要是死了会怎样」「我留了信」——**沟通也算行为** |
| 4 | **自杀意念与自杀相关情绪** | 优先级最低，但不等于不处理 |
| + | **对他人的迫近伤害** | 与 1 同级处理（涉及告知/保护义务） |

**注意第 3 条**：把「说出来」也当作目标行为，不是为了惩罚坦诚，而是为了做功能分析——
这句话在此刻起了什么作用（求助？表达绝望？影响对方？）。处理方式是**分析功能**，
不是「因为你说了所以要送医」。

### 4.3 危机会谈中的即时排序流程

```
        有正在进行的伤害/已服药/已受伤？
                │是                    │否
                ▼                      ▼
        立即医疗处置(120)        本周有自杀/自伤行为？
        稳定生命体征             │是            │否
        评估延后                 ▼              ▼
                          做该行为的链分析   有意念/准备行为？
                          + 安全计划         │是        │否
                          + 手段限制          ▼          ▼
                                        风险分级    处理②③④
                                        + 安全计划
```

### 4.4 偶联管理与「24 小时规则」

- 自伤/自杀行为**之后**，不要立刻给予额外的温暖关注、延长通话、加开会谈——
  那会把关注变成行为的后效（强化）。
- Linehan 的 **24 小时规则**：自伤行为发生后 24 小时内不进行常规电话教练
  （**医疗急救不受此限**）。目的是让「求助」而非「行为」获得帮助。
- 反过来：**在行为发生之前的求助，要给予快速、可靠的回应**——这是这条规则成立的前提。
  只执行「事后冷处理」而不提供「事前可及性」，就是又一次无效化。
- 制度层面同理：如果只有「说要自杀」才能拿到床位/会谈/关注，系统就在训练升级。

### 4.5 常见排序错误

| 错误 | 为什么错 |
|---|---|
| 因为当事人更想谈人际冲突，就跳过本周的自伤 | 一级目标不由话题偏好决定 |
| 「她一直都这样」，所以不再每次评估 | 慢性风险 ≠ 可以不评估当次（见 §9） |
| 整场会谈只谈自杀，不留时间做技能 | 一级处理完要下移，否则会谈变成风险问询 |
| 治疗师自己迟到/失约不算「治疗干扰行为」 | ② 是**双向**的，包括治疗师一侧 |

# 第二部分 · 高风险行为的结构化初评

> **结构化 ≠ 问卷化。** 结构指的是「不遗漏维度、可被复核、可被记录」，
> 而不是照着清单逐条念。把问题嵌进对话里，边问边验证（V5），
> **评估本身就是干预**：被认真、具体、不带评判地问及自杀，本身会降低羞耻和唤起。
>
> **不要把评估当预测。** 没有任何量表能预测个体是否会自杀；
> 评估的目的是**定位当前的照护强度需求**（risk formulation），不是给出概率。

## 5. 评估的四个象限

```
                    ┌─────────────────────────┬─────────────────────────┐
                    │  ① 急性危险            │  ② 慢性风险            │
      风险侧        │  状态性、当下、可变     │  特质性、基线、长期     │
                    │  决定「今天做什么」     │  决定「长期照护结构」   │
                    ├─────────────────────────┼─────────────────────────┤
                    │  ③ 保护因子            │  ④ 立即升级讯号        │
      抵消 / 触发   │  只在低唤起时有效       │  出现任一 → 中止常规流程│
                    │  不能抵消 ①            │  → 直接进入升级阶梯     │
                    └─────────────────────────┴─────────────────────────┘
```

四个象限必须**分开记录**。最常见的临床失误，就是用 ② 和 ③ 把 ① 说服掉：
「他一直有意念」+「他有孩子」→ 于是没有认真处理「今晚手边有一整瓶药」。

## 6. 自杀风险的要素式探询

### 6.1 八个维度（建议顺序：由远及近、由抽象到具体）

**① 意念（ideation）**

- 被动 vs 主动：「希望睡着就不要醒」↔「想结束自己的生命」——**两者都要问**
- 频率、每次持续时间、强度（0–10）、是否侵入性、能否被打断
- 近两周 vs 此刻（「现在，就在我们说话的这会儿，有多少？」）

**② 计划（plan）**

- 具体程度：方法、地点、时间；是否已经在脑中演练
- **对致死性的主观认知**（比客观致死性更重要：以为吃 20 片感冒药会死的人，意图是真实的）
- 有没有考虑过「怎么不被发现」

**③ 手段（means）**

- 是否可得、多快能拿到；有没有**囤积**（攒药）、购买、借用
- 家中是否有枪支/农药/高浓度药物/绳索；是否住高层
- **这一条决定了手段限制的具体动作**（§13.2）

**④ 意图（intent）**

- 主观意图强度（0–10）；矛盾心理有多少
- **阻止因素（deterrents）**：「是什么让你到现在还没做？」——这一问同时采集保护因子
- 对结果的期待：是想死，还是想让某件事停止/让某人知道？

**⑤ 预备与演练行为（preparatory behavior）— 强信号**

- 写遗书/告别信息、分送物品、安排宠物、注销账号、整理财务
- 去过现场、买过工具、试过剂量、把绳子系好又解开
- 「突然的平静」：长期绝望后忽然情绪转好且事务井然——**高度警惕**

**⑥ 既往史（history）**

- 既往尝试：次数、**最致命的一次**、最近一次、当时的意图与**事后是后悔还是遗憾没成功**
- **中断（interrupted）与中止（aborted）的尝试**：被他人阻止或自己停下的——
  这是**最强的预测因子之一**，且极易被漏问
- 家族自杀史、近亲或同伴近期自杀（暴露效应）

**⑦ 控制感与冲动性**

- 能否在冲动来时撑住？过去撑住过吗，靠什么？
- **当前是否饮酒/用药**——急性中毒会同时提高冲动性并降低判断力
- 是否有命令性幻听、解离状态下的「断片」行为

**⑧ 功能分析（DBT 视角，决定干预方向）**

| 自杀/自伤行为的功能 | 对应的干预方向 |
|---|---|
| 逃离无法忍受的情绪 | 痛苦承受技能（TIP）、情绪调节、暴露 |
| 沟通痛苦（「没人相信我有多难」） | 人际效能技能、教环境如何回应、家属会谈 |
| 影响/惩罚他人 | 偶联管理、人际效能、界限工作 |
| 自我惩罚（羞耻驱动） | 羞耻的相反行动、自我验证、创伤工作 |
| 终止解离/找回真实感 | 接地技术、解离处理，**而非**单纯的行为契约 |

### 6.2 提问的措辞

**要**：直接、具体、平常心。
「你有没有想过要结束自己的生命？」「有没有想过具体怎么做？」「家里有药吗？在哪里？」

**不要**：

- 诱导性否定：「你不会想做傻事吧？」「你应该没想过自杀吧？」（等于要求对方否认）
- 委婉到失真：「你有没有想过……不在了？」（对方可以合法地理解成别的意思）
- 道德化：「你想过你父母吗？」（制造羞耻，关闭对话）
- 一次问一串：「你有没有意念、计划、手段、意图？」（得到的是一个「没有」）

**问不出来时**：不要反复追问同一句。改用规范化 + V5：
「很多人到这个份上都会闪过『不如算了』的念头，这很常见。你有过吗？」

### 6.3 工具的位置

- **C-SSRS**（哥伦比亚自杀严重程度评定量表）：目前最常用的结构化问询框架，
  分意念严重度（1–5 级）、意念强度、行为（含中断/中止/准备行为）、致死性。
  **它是「问全」的脚手架，不是分诊评分器。**
- **LRAMP**（Linehan 风险评估与管理方案）：DBT 体系内的评估 + 处置 + 记录一体表，
  强调把「做了什么、为什么这么决定」写下来。
- **Reasons for Living Inventory**：系统采集保护因子。
- **不推荐**：SAD PERSONS 等加总评分法用于分诊——预测效度差，且会制造虚假的安全感。
- **不推荐**：把「不自杀契约（no-suicide contract）」当作风险管理手段——
  **无证据显示其能防止自杀**，且可能抑制坦诚。要用**安全计划**替代（§13）。

## 7. 非自杀性自伤（NSSI）

**必须与自杀行为分开评估**，但两者高度相关：NSSI 是后续自杀尝试的强预测因子之一。
**关键提问：当次行为的意图要单独问**——同一个人在不同次行为中意图可以不同。

### 7.1 评估维度

| 维度 | 具体问什么 |
|---|---|
| 方法 | 切割、烧灼、撞击、抓挠、拔毛、吞咽异物、勒缢 |
| 频率与趋势 | 每周几次？最近 1 个月比之前**多了还是少了**？ |
| 部位与程度 | 部位（手臂/大腿/躯干/颈部）、深度、是否需要缝合 |
| 医疗后果 | 是否曾需就医？有无感染、神经/肌腱损伤 |
| 功能 | 情绪调节 / 自我惩罚 / 抗解离（「想感觉到自己还在」）/ 人际沟通 / 归属 |
| 成瘾特征 | 是否需要「加量」才有效？是否有冲动前的强烈渴求？ |
| 与自杀的关系 | **这一次，有没有想死的意思？** 有没有过「一边割一边想着算了就这样」 |
| 掩盖 | 穿长袖、拒绝体检——说明羞耻水平，影响沟通方式 |

### 7.2 需要医疗处置的 NSSI（不看意图，看伤情）

- 深达皮下脂肪/肌腱/血管、持续出血、伤口张开需缝合
- **颈部勒缢痕迹——无论意图如何一律按高危处理**（缺氧性脑损伤、延迟性喉头水肿）
- 烧伤面积较大或深度烧伤、吞咽异物/电池、注射非医疗物质
- 感染征象（红肿热痛、发热、化脓）
- **任何服药过量**，即便当事人说「就吃了几片」——需按剂量与成分核实，
  对乙酰氨基酚（扑热息痛）过量早期可无症状而肝损伤已发生

### 7.3 回应姿态

不惊慌、不评判、不表演关心；先处理伤口（务实），再做功能分析（好奇）。
**避免**：「你怎么能这样对自己」「答应我不要再做了」——前者制造羞耻，后者制造隐瞒。

## 8. 其他高风险行为

| 类别 | 需要问到的核心 | 急性指征 |
|---|---|---|
| **物质过量/混用** | 种类、剂量、时间、是否与酒精/苯二氮䓬混用 | 意识改变、呼吸抑制、同时有自杀意图 → 120 |
| **进食障碍的躯体风险** | 限制时长、清除行为频率、体重变化速度、晕厥 | 心律失常、低钾/电解质紊乱、严重低体重、再喂养风险 → 躯体急诊 |
| **危险驾驶 / 「不在乎死活」行为** | 是否是隐性自杀行为（「撞上去也无所谓」） | 计划性的「意外」 |
| **对他人的暴力** | 对象是否特定、有无手段、有无计划、既往暴力史 | **特定对象 + 手段 + 意图 → 触发保护/告知义务与报警考量** |
| **失联 / 离家出走** | 是否拒绝告知位置、是否在断联前告别 | 拒绝提供位置 + 计划明确 → 立即定位与报警 |
| **严重自我忽视** | 进食、用药依从、躯体疾病失控 | 被动性自杀的一种形式 |
| **正在遭受的伤害** | 家暴、性侵、霸凌、经济控制 | **未成年人/无民事行为能力人 → 强制报告** |
| **高危性行为 / 无保护冲动行为** | 是否为情绪调节功能 | 纳入 ③ 级目标，除非伴随急性风险 |

**共病放大器**（任何一项都提高上述所有行为的当下危险度）：
急性中毒、失眠数日、急性精神病性症状（尤其命令性幻听）、激越型抑郁、
混合状态、近期停药、谵妄或器质性因素。

## 9. 急性危险 vs 慢性风险

这是整份评估里**最容易出错、也最影响处置**的区分。

| 维度 | **急性危险（acute）** | **慢性风险（chronic）** |
|---|---|---|
| 性质 | 状态性、当下的 | 特质性、基线的 |
| 时间尺度 | 小时～数周 | 数月～数年 |
| 内容 | 意念强度骤升、新出现的计划/手段、准备行为、急性诱发事件、急性中毒、近期出院/近期尝试 | 既往多次尝试、人格与情绪调节障碍、慢性疼痛、物质使用障碍、长期意念、创伤史、孤立、慢性疾病 |
| 可变性 | 可随干预在数小时内下降 | 只随长期治疗缓慢改变 |
| 决定什么 | **今天/今晚的处置强度** | **长期照护结构**（治疗模式、频率、团队） |
| 误用后果 | 忽视 → 漏掉可预防的死亡 | 误当急性 → 反复住院、医源性损害、联盟破裂 |

### 9.1 「急性叠加慢性」（acute-on-chronic）

慢性高风险者的急性升高，**风险是叠加而非替代**，且是绝对风险最高的一类情形。

> **判断基准是「此人自己的基线」，不是人群基线。**
> 一个长期每天都有意念的人说「今天和平时一样」，与一个从不曾有意念的人
> 第一次说「有点想」——两者的**变化量**都需要被认真对待。
>
> 所以初评必须问出基线：「你平时这个念头有多强？今天是几分？」

### 9.2 两个方向的临床陷阱

- **「她一直都这样」**（慢性化偏差）：用长期风险解释掉急性升高。
  → 每次会谈都要重新问**当次**的意念强度、手段可得性、最近一次行为。
- **「有意念就必须住院」**（过度反应）：对慢性高风险者，非自愿住院往往
  强化行为、破坏自主与联盟，且出院后 30 天是**风险最高的窗口之一**。
  → 住院用于**急性、可逆、需要环境限制**的危险，不用于慢性痛苦本身。

## 10. 保护因子及其失效条件

| 类别 | 具体内容 |
|---|---|
| **内部** | 拒绝自杀的理由（子女、宠物、未完成的事）、对死亡/疼痛的恐惧、宗教或道德立场、既往成功撑过危机的经验、求助意愿、问题解决能力、对未来的具体计划 |
| **外部** | 可及且愿意到场的支持者、稳定住所、经济基本安全、治疗联盟与可及的照护、**手段已被限制**、学业/工作联结、照护他人的责任 |

### 10.1 三条必须记住的限制

1. **保护因子不能抵消急性危险。** 「她有两个孩子」不构成今晚可以不处理的理由。
2. **高唤起时保护因子会失效。** 认知窄化会让人**想不起**拒绝自杀的理由——
   所以要在低唤起时把它们**写下来**，放进安全计划里（§13）。
3. **别用保护因子说服自己降级。** 如果你发现自己在列保护因子来缓解**自己的**焦虑，
   停下来，去找督导或咨询团队。

**唯一在高唤起时仍然可靠的保护因子是「手段不可得」**——这是手段限制被强调的原因。

## 11. 需要立即升级处置的讯号（红旗清单）

> **出现以下任意一条：中止常规评估流程，进入升级阶梯。**

### A. 正在发生
- [ ] 正在实施伤害行为 / 已服药 / 已受伤 / 已在高处或现场
- [ ] 意识水平下降、言语含糊、呼吸异常（可能已过量）
- [ ] 颈部有勒缢痕迹（无论意图）

### B. 迫近
- [ ] **具体计划 + 手段可得 + 近期时间点**（三者同时具备）
- [ ] 已完成准备行为：遗书、分送物品、安排后事、到过现场
- [ ] 明确说出意图且**拒绝**任何安全计划、拒绝与任何人联系
- [ ] 长期绝望后**突然平静**、事务突然井然
- [ ] 命令性幻听指令自伤/伤人；急性精神病性状态、谵妄、严重激越
- [ ] 急性中毒 **且** 有自杀意念
- [ ] 对特定对象的伤害意图 + 手段 + 计划

### C. 高危窗口（不一定立即，但需当日处置与密集随访）
- [ ] **近 30 天内精神科出院**
- [ ] **近 3 个月内有自杀尝试**（含中断/中止的尝试）
- [ ] 重大丧失/羞耻曝光事件刚刚发生（分手、失业、被公开指控、司法传唤、债务爆雷）
- [ ] 手段刚刚变得可得（拿到药、买到工具、搬进高层）
- [ ] 近期停用精神科药物或刚调整剂量
- [ ] 支持系统刚刚断裂（唯一支持者离开/去世/切断联系）

### D. 情境性
- [ ] 未成年人、或无人照看、或正处于施害者同一空间
- [ ] 拒绝提供位置且联系中断风险高
- [ ] 无法自行到达医疗资源且独居

### 11.1 升级阶梯（按强度递增，**优先选最低有效强度**）

```
 1. 延长当次会谈 / 当场降唤起（TIP）+ 立刻制定安全计划
 2. 手段限制：当场移除或交由他人保管（这一步常常比转介更有效）
 3. 当日/次日加开会谈 + 约定电话教练 + 明确的联络时间点
 4. 知情同意下通知紧急联系人 / 家属到场陪同
 5. 危机热线 / 移动危机干预团队 / 社区精神卫生中心
 6. 陪同至精神科急诊或综合医院急诊评估
 7. 呼叫急救（120）/ 报警（110）——用于生命体征受威胁、
    当事人失联、拒绝且无行为能力、或现场有他人危险
```

**执行要点**

- **任何时候不让处于迫近危险中的人独处**，包括「去洗手间」「我打个电话」。
- 打破保密前，尽可能先**告知**（「我要联系你姐姐，我们一起决定怎么说」）——
  把不可协商的部分和可协商的部分分开，这是 §2.2 里那组辩证的落地。
- 保密例外应在会谈**开始时**就说明，而不是在触发时才第一次提起。
- 转介不等于交接完成：**确认对方接手**，并记录时间、对象、内容。

## 12. 一次 20–30 分钟初评的会谈结构

| 阶段 | 时间 | 做什么 | 不做什么 |
|---|---|---|---|
| ① 定向与知情 | 2′ | 说明目的、时长、保密与其例外 | 不跳过保密例外 |
| ② 降唤起与验证 | 3–5′ | V1→V5；必要时先做一次配速呼吸 | 不在这阶段问细节 |
| ③ 当下处境 | 3′ | 「今天发生了什么让你现在坐在这」 | 不追溯童年史 |
| ④ 风险探询 | 8–10′ | §6 八维度 + §7 NSSI + §8 其他 | 不照本宣科念清单 |
| ⑤ 功能分析 | 3′ | 这个行为/念头此刻**起什么作用** | 不做完整链分析 |
| ⑥ 分级与决策 | 2′ | 四象限归位 → 选最低有效强度 | 不当场做长期治疗规划 |
| ⑦ 安全计划 | 5′ | §13 六步，**写下来，给对方一份** | 不用口头「答应我」替代 |
| ⑧ 收尾与承诺 | 2′ | 明确下一个联络时间点；确认今晚的第一步动作 | 不以「有事打给我」结束 |
| ⑨ 记录与咨询 | 会谈后 | §14；必要时当天找督导/团队 | 不拖到下周再写 |

**③–④ 之间的桥接句式**：
「你说的这些我听见了，都很重的东西。接下来我要问一些很直接的问题，
是我对每个处在这种处境的人都会问的，问完我们再一起决定今晚怎么办——可以吗？」

## 13. 安全计划与手段限制

### 13.1 安全计划（Stanley-Brown 六步）

必须**由当事人自己的话写成**、书面化、随身可及（纸质 + 手机照片）。

1. **预警信号**：我快不行了的迹象是什么（想法/情绪/身体/行为，要具体到可识别）
2. **我自己能做的**（不需要任何人）：3 项，写清楚在哪做、用什么
3. **能分散注意的人或场所**（不必谈自杀，只要在一起）
4. **可以求助的人**：姓名 + 电话 + 说什么（把开场白也写好）
5. **专业与紧急资源**：治疗师、热线 12356、当地急诊、120/110
6. **让环境变安全**：具体移除什么、由谁保管、放到哪、什么时候取回

**DBT 的补充**：把 §3.2 的技能卡和 §10 的「拒绝自杀的理由」直接贴进第 2、3 步——
因为高唤起时想不起来。并用**承诺策略**（脚在门内、自由选择与无替代方案、
联系过去的承诺、塑造）来取得对计划的真实承诺，**而不是让对方签「不自杀契约」**。

**排障（troubleshoot）是必需步骤**：
「如果到时候你姐姐没接电话，你会怎么办？」——没排障过的计划在危机中会直接失效。

### 13.2 手段限制咨询（lethal means counseling）

**这是单次干预里证据最强、见效最快的一项**，但最常被跳过。

- 具体化：不是「把危险物品收起来」，而是「那瓶药现在在哪？谁能今晚就拿走？拿到哪里去？」
- 找**第三方保管人**，并让当事人参与决定交给谁（保留自主）
- 明确**取回条件**（不是永久没收，而是「等这阵过去，我们一起决定」）
- 关注**延迟**的价值：自杀危机常常是数分钟到数小时的窗口，**增加取得手段的时间成本本身就在救命**
- 家属在场时，把这一步讲成「共同的临时安排」，而非监管或惩罚

---

## 14. 记录：写风险个案解析，不写风险预测

**不要写**：「低风险 / 中风险 / 高风险」然后结束。这既不可辩护，也对下一位接手者无用。

**要写**（LRAMP 的精神）：

1. **采集到的事实**：意念强度、计划具体度、手段可得性、意图、近期行为、中毒状态
2. **四象限归位**：急性因素 / 慢性因素 / 保护因子 / 红旗（分别列出）
3. **临床解析**：为什么这些事实合起来指向这个照护强度（推理过程）
4. **处置决定与理由**，**包括没做什么以及为什么**
   （例：「未安排住院，理由是：无新增计划、手段已由母亲保管、同意次日复诊、
   既往住院曾导致行为升级，故选择加密随访 + 手段限制」）
5. **安全计划要点**与已交付的副本
6. **协商与告知**：通知了谁、何时、内容
7. **咨询记录**：是否与督导/咨询团队讨论、结论
8. **下一次接触的确切时间**

> 写下推理过程，在临床上是为了让下一位接手的人能接上；
> 在伦理和法律上，**可辩护性来自决策过程的合理性，而不是结果**。

## 15. 评估者自身与伦理边界

- **恐惧驱动的处置**：当你的主要动机是「我不想担责」时，最容易做出过度限制的决定。
  识别它，说出来（在督导里），再决定。
- **慢性化的麻木**：反复危机会让人脱敏。**用结构（本文档）对抗脱敏**——
  正因为可能变麻木，才需要每次都走同样的维度。
- **一致性与团队**：DBT 体系里，治疗师同样需要被验证和被挑战——
  **咨询团队不是可选项**。高风险个案不应由个人独自承担。
- **能力边界**：本文档不能让未受训者具备处理自杀危机的资质。
  受训、督导、本地转介网络是不可替代的。
- **文化与语境**：羞耻、家庭结构、对精神科的污名、对报警的恐惧，
  都会改变当事人愿意说什么。评估方式要随之调整，**风险维度不变，问法可变**。
- **法律/制度**：保密例外、强制报告（未成年人受侵害）、告知与保护义务的具体要求
  依辖区而定，机构应有成文流程，从业者应事先知晓。

## 附：与本仓库的关系

本文件是**知识参考资料**，不接入 `core/agent.js` 的认知循环，
也**不应**被实现为 agent 的自动分诊逻辑。

如果将来要做面向心理健康场景的模块，本文档的立场是：
**任何检测到风险讯号的对话系统，唯一正确的行为是提供求助资源并转向人类，
而不是自行评估、分级或处置。** §11 的红旗清单可以用作「何时转人工」的触发条件，
但不能用作「系统自己决定风险等级」的评分表。
