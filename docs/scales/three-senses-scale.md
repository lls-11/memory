# 三感量表（TSS）编制方案

**Three-Senses Scale — 无助感 · 无意义感 · 绝望感**

> 配套：结构诊断与计分脚本 [`tss-scoring.js`](./tss-scoring.js)
> 制作流程与验证关卡：[`BUILD-PROCESS.md`](./BUILD-PROCESS.md)（每步的数字门槛与留痕要求）
> 可直接施测的卷面：[`tss-30-form.html`](./tss-30-form.html)（30 题打乱呈现、即时计分与剖面图、作答质量自检，可打印）
> 理论与实验基础：[`../experiments/three-senses-loop.md`](../experiments/three-senses-loop.md)

---

## 1. 为什么还要一个新量表

已有 Beck 绝望量表（BHS）、生命意义问卷（MLQ）、一般自我效能感量表、习得性无助
量表等。新量表必须先回答「凭什么」——本方案的三条理由：

1. **它们互不通话**。三个构念分散在三套独立的测量传统里，量程、时间框架、
   作答格式都不同，无法在同一个模型里比较三者的相对水平与动态关系。
2. **没有一个量表建立在三者的结构关系上**。本量表的维度不是经验地「跑出来」的，
   而是从动机链的三处断裂**演绎**出来的（§2），因此三个分量表天然可分、
   且可预测彼此的因果顺序。
3. **缺少能测「循环」的条目**。三感的临床危害在于自我强化，而其铰链是
   **预先放弃**（还没试就不试了）。现有量表都不测这个。TSS 把它做成独立模块（§2.4）。

**如果做不到以下任一点，这个量表就不该发表**（预注册的否证条件）：

- 三个分量表在双因子模型中 ωHS ≥ .30（否则只是负性情绪的三种措辞 → §6.2）
- 控制 PHQ-9 与 BHS 后，TSS 对自杀意念/行为坚持仍有增量效度 ΔR² ≥ .03（§7.4）
- 三个分量表对三种实验诱导呈**差异性**反应（操纵-分量表矩阵对角显著 → §8）

## 2. 维度结构：从动机链演绎，而非从数据探索

动机要成立需要一条完整的链，三感各自打断一处：

```
        行动  ──①──▶  结果  ──②──▶  价值  ──③──▶  未来
                 ↑             ↑             ↑
              无助感        无意义感        绝望感
```

每个领域再按其构念自身的成熟分解切成 3 个侧面（facet）：

### 2.1 无助感 H（行动 → 结果）
| 侧面 | 内容 | 与既有构念的关系 |
|---|---|---|
| H-a 随因失联 | 行动与结果之间没有联结 | 习得性无助的核心（response–outcome independence） |
| H-b 控制外置 | 决定权在我之外 | 接近外控信念，但限定在「我不能影响」而非「谁在影响」 |
| H-c 无效努力 | 已投入的努力落空 | 区别于自我效能（我没能力）——这里是我有力气但不起作用 |

### 2.2 无意义感 M（结果 → 价值）
沿用意义的三成分（目的 / 重要性 / 连贯性），取其**缺失极**：
| 侧面 | 内容 |
|---|---|
| M-a 重要性缺失 | 做成了也不重要、没人在意（mattering 的反面） |
| M-b 目的缺失 | 说不出在为什么忙 |
| M-c 连贯性缺失 | 经历讲不通、各件事对不上 |

### 2.3 绝望感 D（价值 → 未来）
| 侧面 | 内容 |
|---|---|
| D-a 未来负性预期 | 以后只会更差 |
| D-b 不可改变性 | 已经定了、改不动（稳定-全局归因） |
| D-c 未来视野塌缩 | 想不出以后的自己、无法计划（foreshortened future） |

### 2.4 循环模块 PD：预先放弃（Preemptive Disengagement）

这是 TSS 相对已有量表的**独有内容**，对应闭环边「绝望 → 无助」的机制：
预期不会变好 → 索性不试 → 不再有机会体验到行动确实有效 → 无助被自己的不行动证实。

**一个刻意的设计决定**：不去问「你觉得这几种感觉在互相加重吗」。
让人内省报告自己的因果循环在心理测量上不可靠。改为测量这个循环的**行为铰链**
（还没开始就已放弃），它可观察、可被他人评定、也可被实验操纵。

PD 作为**独立模块**，不计入三感总分（`tss-scoring.js` 的 `TOTAL` 只含 H/M/D），
避免污染三维结构的检验。

## 3. 作答格式与时间框架

| 版本 | 代号 | 题数 | 时间框架 | 量程 | 用途 |
|---|---|---|---|---|---|
| 条目池 | TSS-53 | 53 | 过去两周 | 1–5 | 仅用于编制阶段 |
| 完整版 | **TSS-30** | 30（H/M/D 各 9 + PD 3） | 过去两周 | 1–5 频率 | 研究与临床主用 |
| 简版 | TSS-12 | 12（各 4） | 过去两周 | 1–5 | 大样本流调、重复测量 |
| 状态版 | TSS-S12 | 12（各 4） | **此刻** | 1–7 同意度 | 实验室多轮测量与 EMA |

**为什么特质版用 5 点频率而状态版用 7 点同意度**：特质版要与 PHQ-9 一类临床工具
对齐、便于切分点推导，频率锚点（几乎没有 / 有几天 / 一半以上的日子 / 几乎每天 /
一直如此）比同意度更不易受作答风格影响；状态版要捕捉单轮之间的细微变动，需要更多
刻度，且「此刻同意程度」比「频率」在几分钟的窗口内更有意义。
**两版不可换算**，需分别建立常模（§7.6）。

TSS-S12 即上一份实验设计中 Study 2 使用的状态量表，条目见
[`../experiments/three-senses-loop.md`](../experiments/three-senses-loop.md) 附录 A。

## 4. 条目撰写规则（用于筛查条目池）

每个候选条目必须同时满足：

- **单一命题**：不含「而且 / 因为」，不双筒（double-barreled）
- **不含否定词嵌套**：避免「我不觉得没有意义」
- **口语、短**：≤ 20 字，初中文化程度可读
- **不与躯体症状重叠**：不出现睡眠、食欲、体重、疲劳——这是与 PHQ-9 保持区分的关键
- **不写因果**：不出现「所以」「因为」「导致」「因此」，也不出现目的连词「免得」
  （因果留给模型，不写进条目）。确有构念上不可去除的连词时，须**登记为例外**并写明理由（见 `verify.js` 的 `CONNECTIVE_EXCEPTIONS`），在阶段 2 专家评审中逐条复核
- **不含自杀内容**：TSS 不做风险筛查，风险评估由独立工具承担（§9）

**反向题**：条目池含 10 题反向（每侧面 ≥ 1），正式版保留 ≤ 3（每领域 1）。
预注册检验「反向题方法因子」：若加入方法因子后 ΔCFI ≥ .01，则正式版不保留反向题，
改用注意检查题防止定势作答。

**与既有量表的条目重叠审计**：编制阶段须逐条与 BHS(20)、MLQ(10)、GSES(10)、
PHQ-9(9) 做语义比对，重叠度过高（专家判定为「实质同义」）的候选条目删除。
这一步的结果要作为附录发表——否则「新量表」的合法性无法辩护。

## 5. 计分

- 反向题按 `1↔5`（状态版 `1↔7`）折算后，各分量表取**已答条目均值**（非总和，
  便于跨版本比较）。
- **缺失规则**：某分量表缺失 > 25% 则该分量表不计分；三感总分 = H/M/D 三个
  分量表均值的平均，任一为空则总分为空。不做插补。
- **PD 不计入总分**，单独报告。
- 实现见 `tss-scoring.js` 的 `score()`。

### 不认真作答筛查（预注册排除标准）

`carelessFlags()` 输出三个指标，命中任一即标记**待人工核查**（不自动删除）：

| 指标 | 默认阈值 | 抓什么 |
|---|---|---|
| 最长同一答案连续串 | ≥ 15（= 题数的一半） | 一路点同一档 |
| 个体内反应变异 IRV | < 0.30 | 无变异（含全选中间档） |
| 反向题偏离 | ≥ 2.0 分 | 没读题、定势作答 |

**阈值必须按样本校准，不能照抄。** 长串指标对**内容同质性**极其敏感：
TSS 三个维度高度相关，一个真实的高分被试连答 9–10 个「4」完全合理，
用固定的「≥10」会把最需要关注的人误删。两条操作规则：

1. 长串在**整份问卷（含其他量表）**上计算，而非只在 TSS 的 30 题内；
2. 阈值取本样本 longString 的 99 百分位与 IRV 的 1 百分位，再人工核查被标记者。

脚本的自检输出可以看到这个区分：「全选 5 且反向题正确反选」的极端高分被试通过筛查，
而「全选 5 含反向题」与「全选 3」被标记。

## 6. 结构检验（编制的核心环节）

### 6.1 双样本策略

| 样本 | N | 用途 |
|---|---|---|
| 样本 1 | 600 | 条目分析 + EFA/并行分析 + GRM 条目筛选 → 定出 TSS-30 |
| 样本 2 | 600 | **独立** CFA + 双因子 / ESEM 竞争模型比较 |
| 重测 | 200 | 2 周重测 ICC |
| 临床 | 150 患者 + 150 匹配对照 | 已知组效度、切分点 |
| 实验 | 见 §8 | 实验效度 |

条目池 53 题，样本 1 的被试:条目比 ≈ 11:1，满足常规要求。

**条目筛选判据**（样本 1，预注册）：
- 描述统计：|偏度| ≤ 2、天花板/地板反应 < 20%
- 校正后条目-总分相关 ≥ .40
- EFA 主负荷 ≥ .50 且交叉负荷 ≤ .32
- GRM（分级反应模型）区分度 a ≥ 1.0；阈值覆盖整个特质范围
- 条目信息函数冗余者删除（保留覆盖不同 θ 区段的条目）
- 依 lordif 检验性别/年龄 DIF，有显著 DIF 且效应不可忽略者删除

### 6.2 三维结构的生死判据

竞争模型：单因子 / 三因子相关 / 二阶 / **双因子** / ESEM。
拟合判据：CFI、TLI ≥ .95，RMSEA ≤ .06，SRMR ≤ .08（WLSMV，序数数据）。

**关键不是拟合，而是分量表分数能不能单独解释。** 由双因子指标判定
（`bifactorIndices()` + `verdict()`）：

| 指标 | 判据 | 含义 |
|---|---|---|
| ωH（一般因子） | — | 总分中归于一般因子的可靠方差 |
| **ωHS（各分量表）** | **≥ .30** | 剔除一般因子后分量表自身的可靠方差 |
| ECV | ≥ .70 → 本质单维 | 一般因子解释的共同方差比例 |
| H | ≥ .80 | 因子可复制性 |

**PUC 只报告、不设门槛**：它由「维度数 × 每维题数」决定，与数据无关
（等题数时 PUC = (m−1)k/(mk−1)，3×9 恒为 .692，3×3 恒为 .750）。
把 PUC ≥ .70 当硬门槛会让 3×9 设计永远判不出单维。低 PUC 只提示 ωH 可能被高估，
故判定以 ECV 为主。

脚本内置三个对照情景的实算结果：

| 情景 | 一般/特异负荷 | ωH | ECV | 各 ωHS | 判定 |
|---|---|---:|---:|---:|---|
| A | .45 / .60 | .598 | .360 | .589 | 三维成立，三个分量表可各自解释 |
| B | .75 / .25 | .942 | .900 | .094 | **三维失败**，应改为单维总分 |
| C | .62 / .45–.35 | .828 | .667 | .320/.370/.218 | 部分成立（绝望分量表未过） |

情景 C 是实际研究中最可能出现的样子，也是最需要预先想好处置方案的：
**若某一分量表 ωHS < .30，处置顺序为**（预注册）
(1) 检查该领域三个侧面是否被条目筛选压成了同质内容 → 补足侧面覆盖后重测；
(2) 仍不过 → 该领域降为「总分的一个侧面」，不单独报分，并在论文中明确声明；
(3) 三个都不过 → 放弃三维结构，TSS 改为单维「士气损耗」量表，
并撤回 §1 的第 2 条立论。**不允许**靠加载荷、删条目把 ωHS 调到阈值以上。

### 6.3 测量等值性

- 跨性别、跨年龄段、**临床 vs 非临床**：configural → metric → scalar，
  判据 ΔCFI ≤ .01、ΔRMSEA ≤ .015。
- **纵向等值性**（状态版 8 个时点）：这是把 TSS-S12 用于 §8 多轮实验的前置条件，
  不过则不能把轮次间的分数差解释为真实变化。

## 7. 信度与效度

### 7.1 信度
- 内部一致性：报告 ω（不只 α）与各分量表 ωS
- 2 周重测：特质版 ICC(2,1) ≥ .70；**状态版反而应当低**（它测的是状态）
- **状态-特质方差分解**：对状态版做潜在状态-特质模型或概化理论分析，
  报告状态方差占比 ≥ 40%——否则「状态版」名不副实

### 7.2 聚合效度（预期 r）
| 对照量表 | H | M | D |
|---|---|---|---|
| BHS 绝望 | .40–.55 | .40–.55 | **.65–.80** |
| MLQ-Presence（反向） | .35–.50 | **.65–.80** | .40–.55 |
| 一般自我效能（反向） | **.55–.70** | .30–.45 | .35–.50 |

**每个分量表与自己的「对口」量表相关最高**，这一模式本身就是判别效度的证据；
若三个分量表与三个外部量表的相关大小不可区分，则 §1 立论失败。

### 7.3 区分效度
- 社会赞许性（Marlowe-Crowne 短版）：|r| ≤ .20
- 特质乐观（LOT-R）：应与 D 相关最强，但 |r| < 与 BHS 的相关
- **与躯体性抑郁症状（PHQ-9 的睡眠/食欲/精力题）**：|r| 应明显低于与认知性症状的相关

### 7.4 增量效度（最重要的一条）
分层回归：Step1 人口学 → Step2 PHQ-9 + BHS → Step3 TSS 三个分量表。
**判据：ΔR² ≥ .03（p < .01）**，结果变量：
- 自杀意念（BSSI）
- 行为坚持（不可解任务上的放弃潜时，实验室测）
- 求助行为意向
- 3 个月后的抑郁水平（纵向子样本 n = 300）

若 TSS 在控制 PHQ-9 与 BHS 后没有增量，量表无存在价值。

### 7.5 已知组效度
临床（抑郁障碍诊断，MINI 或 SCID-5 确诊）vs 匹配社区对照：预期 d ≥ 0.8。

### 7.6 常模与切分点
- 分版本（TSS-30 / TSS-12 / TSS-S12）分别建立常模，**不跨版本换算**
- 切分点：以临床诊断为标准做 ROC，报告 AUC、敏感性、特异性、Youden 指数、
  阳性预测值（并明确说明 PPV 依赖于所在人群的基础率）
- **明确声明 TSS 不是诊断工具**，切分点仅作筛查与研究分组用

## 8. 实验效度：这个量表独有的一条验证

一般量表开发止于相关证据。TSS 的三维结构来自可操纵的理论，因此可以**实验地**验证：

把三种诱导（无助 / 无意义 / 绝望，材料见实验设计文档 §4.1）作为自变量，
TSS-S12 的三个分量表作为因变量，得到 **3×3 操纵-分量表矩阵**。

- **判据**：对角效应 ≥ 0.6 SD，非对角 < 0.25 SD。
- 这比任何相关系数都更能证明三个分量表测的是三件不同的事。
- 样本：4 臂（三诱导 + 中性）× n = 45 = **180**，与实验设计文档的 Study 0B 共用一批数据。

**PD 模块的预测效度**：PD 分数应预测实验设计文档 Study 2 中三感的**上升斜率**
（跨层调节效应）。PD 高的人，一次诱导后的放大更强。若 PD 不预测斜率，
则 PD 模块的理论意义不成立，应退为描述性条目。

## 9. 伦理与使用边界

- 条目池**不含**自杀意念条目。若在高风险人群使用，必须**并行**施测独立的风险工具
  （如 C-SSRS）并配备转介流程；不得用 TSS 分数替代风险评估。
- 施测中出现主动披露的痛苦或风险信号时，中止施测并走转介流程。
- 结果反馈给个人时，只反馈维度水平与资源信息，不反馈「你属于高危」这类标签。
- 版权与使用：建议采用允许研究免费使用的授权，条目全文随论文公开
  （不公开条目的量表无法被复制检验）。

## 附录 A：候选条目池（TSS-53）

1–5 = 几乎没有 / 有几天 / 一半以上的日子 / 几乎每天 / 一直如此。时间框架：**过去两周**。
`(R)` = 反向计分。`★` = 进入 TSS-30 正式版的建议题（待样本 1 的实际数据决定，此处仅为先验优选）。

### 领域 H：无助感（行动 → 结果）

**H-a 随因失联**
1. ★ 我做的事和最后的结果之间，好像没什么关系。
2. ★ 不管我怎么努力，事情的走向都差不多。
3. ★ 结果好不好，跟我做了什么没有关系。
4. 我的选择能改变事情的结果。**(R)**
5. 事情会怎样，基本上是碰运气。

**H-b 控制外置**
6. ★ 我的生活由我控制不了的事情决定。
7. ★ 重要的事情上，决定权不在我手里。
8. ★ 遇到问题时，我有办法去影响它。**(R)**
9. 我只能等着看事情怎么发生在我身上。
10. 别人和环境替我决定了大部分事。

**H-c 无效努力**
