# persona-agent 设计文档：一个「像人」的对话智能体框架

> 目标不是做一个更强的助手，而是做一个**更像人的对话对象**。
> 记忆会淡忘、说话有立场、会说"我记不清了"——这些「不完美」都是特性。

## 1. 总体架构：认知循环 + 可插拔模块

核心信念：**agent 核心应该薄到只剩一个循环，一切拟人能力都是模块。**

一轮对话 = 一次认知循环，模仿人处理一句话的心理过程：

```
                 用户说了一句话
                       │
   ┌────────────────── ▼ ──────────────────────────────┐
   │ ① perceive 感知     每个模块"听到"这句话            │
   │                     记忆：注意门控（值得记吗？）      │
   │                     将来→ 情绪：这句话触动我了吗？    │
   ├───────────────────────────────────────────────────┤
   │ ② recall 组装心理语境  每个模块贡献"此刻脑子里有什么"  │
   │                     人格：我是谁                     │
   │                     记忆：我还记得对方什么            │
   │                     技能：我会做什么                 │
   │                     将来→ 情绪：我现在心情如何        │
   ├───────────────────────────────────────────────────┤
   │ ③ think 思考与行动   LLM 依据心理语境生成回复         │
   │                     途中可调用技能（function call）   │
   ├───────────────────────────────────────────────────┤
   │ ④ reflect 反思       每个模块观察这轮完整交流         │
   │                     将来→ 性格微调、经历累积、情绪衰减 │
   └────────────────── │ ──────────────────────────────┘
                       ▼
                    回复用户

   ⑤ idle（不在对话循环里）：离线心理过程
      记忆：睡眠巩固（重放/整合/遗忘）  将来→ 写日记、复盘、做梦
```

### 模块契约

模块 = 一个实现了部分钩子的普通对象，全部钩子可选：

```js
{
  name: 'memory',
  perceive(ctx)            // ① 观察用户输入
  recall(ctx) -> string    // ② 返回心理语境片段（注入 system prompt）
  skills() -> Skill[]      // ③ 提供技能 { name, description, parameters, run }
  reflect(ctx)             // ④ 观察 { userText, reply, usedSkills }
  idle() -> report         // ⑤ 离线过程
  serialize() / restore()  // 持久化
}
```

`ctx` 在一次循环中共享，模块间通过 `ctx.notes`（Map）传递信号——
比如将来情绪模块在 perceive 里写入 `notes.set('mood', 0.3)`，
记忆模块就能拿它当显著性输入（心情激动时记得更牢）。

### 组装方式

```js
const agent = new PersonaAgent({ llm })
  .use(createPersonaModule())    // 我是谁
  .use(createMemoryModule())     // 我记得什么
  .use(createSkillsModule());    // 我会做什么

const { text } = await agent.chat('你好');
agent.idle();                    // 睡一觉
```

**核心永远不用改**——加新的拟人维度就是多一个 `.use()`。

## 2. 当前的三个模块

### 2.1 memory —— 像人一样记忆（本框架的第一块基石）

不用向量库做完美检索，而是用认知心理学理论建模（引擎 `modules/memory/engine.js`，
零依赖约 400 行）：

| 理论 | 行为表现 |
|---|---|
| Atkinson-Shiffrin 多存储模型 | 输入过**注意门控**才进短期记忆（7±2 容量），复述才进长期 |
| Ebbinghaus 遗忘曲线 + 间隔效应 | 不复述就淡忘；间隔复习比填鸭有效 |
| ACT-R 激活方程 | 反复提到的回忆得快；线索会联想激活相关记忆；记忆多了互相干扰 |
| 回忆 vs 识别 | 想不起名字，一给提示就"哦对！" |
| 编码特异性 | 在原语境里记得清，换语境只剩模糊要点 |
| 睡眠巩固 | idle 时重放重要记忆、整合相似记忆、清除衰减殆尽的 |
| 重构式回忆 | 淡化的记忆只返回要点(gist)+置信度，注入提示词时用模糊措辞 |
| 话到嘴边 | 差一点想起来的事，会以"我有印象但想不起来"的形式出现 |

**为什么这对拟人化重要**：一个什么都记得的对话对象立刻暴露自己是机器。
「你上次说的那事儿后来怎么样了？」和「你好像提过……我记不太清了」，
后者才是人。记忆的不完美是人格可信度的地基。

参数速查见 `engine.js` 的 `DEFAULTS`；`timeScale=86400` 表示按天遗忘（生产），
调成 `1` 可以在秒级观察遗忘（调试，`demo/memory-demo.js` 就是这么做的）。

### 2.2 skills —— 程序性记忆（会做的事）

技能即 `{ name, description, parameters, run }`，经 LLM function calling 触发。
内置 now/calc/coin 三个最小示例，`register()` 即可扩展。

留了一个有趣的口子：**技能熟练度**。reflect 钩子能看到 `usedSkills`，
将来可以给每个技能挂一条程序性记忆痕迹——久不用会生疏、常用则熟练，
这也是人的特征。

### 2.3 persona —— 「我是谁」（v0 占位）

当前是静态 JSON 人设（身份/背景/性格/说话方式/原则），站在将来整个
「自我」体系的位置上。默认人设「小忆」：26 岁书店店员，心理学出身，
记性一般但重要的事记得牢——**人设与记忆系统的特性互相印证**，
这是拟人化的一个设计原则：各模块讲同一个关于"这个人"的故事。

## 3. 后续模块路线图（为你的目标预留的接口）

按你的计划（人格/身份/经历/性格），建议拆成这些模块、按此顺序做：

| 模块 | 变化速度 | 主要钩子 | 设计思路 |
|---|---|---|---|
| **identity 身份** | 几乎不变 | recall | 稳定自我事实（名字/年龄/关系网），从 persona 拆出 |
| **biography 经历** | 只增不改 | recall + reflect | **直接复用 memory 引擎**：预置人生经历 = 一批高强度 LTM 痕迹（"18 岁那年…"），与用户的共同经历在 reflect 里累积成新痕迹。自传体记忆和对话记忆是同一套遗忘/联想机制——预置记忆也会淡忘细节、被线索唤醒，天然自洽 |
| **traits 性格** | 缓慢漂移 | recall + reflect | 大五人格之类的连续参数 → 生成语气与决策偏好的提示词；reflect 里按交互微调（漂移要慢：日均变化 < 0.1%） |
| **mood 情绪** | 分钟级 | perceive + recall + reflect | 快变状态：被对话触动（perceive）、影响语气（recall）、向基线衰减（reflect/idle）。**并且调制记忆**：情绪高时 salience 加成（闪光灯记忆）、心境一致性检索（心情差时更容易想起糟心事）——接口就是 `ctx.notes` |
| **diary 日记** | 每日 | idle | idle 时让 LLM 把当天记忆写成第一人称日记，存为 biography 痕迹——「反思性自我」的最小实现 |

**一个统一视角**（这是设计中我觉得最有价值的洞察）：
身份、经历、性格其实都可以看作**不同衰减速度的记忆**——
身份是几乎不衰减的记忆，经历是衰减很慢的记忆，情绪是衰减极快的"记忆"。
如果沿这条路走，整个「自我」可以统一在同一套激活/衰减数学上，
模块只是不同参数的 memory 实例 + 不同的提示词措辞。值得实验。

## 4. 工作记忆的映射

对话历史窗口（`historyWindow`，默认 12 轮）就是 agent 的**工作记忆**：
窗口内逐字在场，滑出窗口的只能靠 memory 模块"想起来"——而想起来的
可能已经只剩要点。短期完美、长期有损，和人一致。

## 5. 目录结构

```
persona-agent/
├── core/
│   ├── agent.js        # 认知循环编排器（~150 行，尽量不再长大）
│   └── llm.js          # LLM 客户端（DeepSeek/OpenAI 兼容 + 演示模式）
├── modules/
│   ├── memory/
│   │   ├── engine.js   # 心理学记忆引擎（独立可复用，零依赖）
│   │   └── index.js    # 模块封装（钩子适配）
│   ├── skills/index.js # 技能模块
│   └── persona/index.js# 人格模块（v0）
├── cli.js              # 命令行聊天（含状态持久化）
├── demo/memory-demo.js # 记忆引擎八种类人现象演示
├── test/smoke.js       # 冒烟测试（无需 API Key）

```

## 6. 快速开始

```bash
npm install
node test/smoke.js            # 验证一切正常（无需 API Key）
node demo/memory-demo.js      # 看记忆引擎的八种类人现象

export DEEPSEEK_API_KEY=sk-... # 或 OPENAI_API_KEY + LLM_BASE_URL/LLM_MODEL
node cli.js                    # 和「小忆」聊天；/memory 看她脑子里有什么
```

关掉再开，她还记得你——但记得的样子像人：反复聊过的记得牢，随口一提的淡忘，
偶尔"话到嘴边"，你给个提示她才"哦对！"。

## 7. 主流框架对照（为什么不直接用 Mem0/Zep/Letta）

它们是优秀的**检索系统**（向量/图存储 + 完美召回），优化目标是"记住一切并精准取回"。
本框架的优化目标相反：**可信的人格**。遗忘、模糊、联想、话到嘴边不是 bug 而是产品
特性。两者不冲突——如果某天需要"绝对不能忘"的事实（用户生日、重要承诺），
可以再挂一个传统检索模块作为"笔记本"（人也会把重要的事写在本子上，
这个隐喻本身就是拟人的）。
